# Internship & Job Application Tracker

## Problem Statement

Students often apply for multiple internships and jobs at the same time. It can become difficult to keep track of company names, job roles, application dates, priorities, application status, and interview details.

The Internship & Job Application Tracker is a command-line based Java application designed to help students organize and manage their internship and job applications in one place. The system allows users to store application details, track application progress, manage interviews, and view application statistics.

## Scope

The project focuses on managing internship and job applications through a command-line interface.

The system allows users to:

- Add new internship or job applications
- View all applications
- Search for an application
- Update application status
- Delete an application
- Set application priority
- Add and view interview details
- Update interview status
- Add interview notes
- View application statistics
- Save application and interview data
- Load previously saved data

The project is intended for personal academic and placement-tracking purposes.

## Target Users

The main target users are:

- College students
- Students applying for internships
- Students preparing for campus placements
- Fresh graduates tracking job applications

## High-Level Features

### 1. Application Management

Users can add, view, search, update, and delete internship or job applications.

### 2. Application Status Tracking

Users can track the progress of applications using the following statuses:

- Applied
- Shortlisted
- Interview
- Selected
- Rejected

### 3. Priority Management

Users can assign a priority to each application:

- Low
- Medium
- High

### 4. Interview Management

Users can store interview details such as:

- Application ID
- Interview date
- Interview time
- Interview type
- Interview status
- Interview notes

### 5. Dashboard and Statistics

The system provides statistics such as:

- Total applications
- Applied applications
- Shortlisted applications
- Interviews
- Selected applications
- Rejected applications
- Selection rate
- Interview rate

### 6. File-Based Data Storage

Application and interview information can be saved to text files and loaded when required.

### 7. Input Validation

The system validates IDs, text fields, priorities, application statuses, and interview statuses to reduce invalid input.
